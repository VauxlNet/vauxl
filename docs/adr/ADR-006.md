# ADR-006: Primary Authentication — WebAuthn (FIDO2)

**Status:** Accepted
**Date:** 2026-01-01

## Context

Password-based authentication is the leading cause of account compromise.
Vauxl targets security-conscious users and enterprises where phishing-resistant
authentication is a requirement.

## Decision

Use WebAuthn (W3C/FIDO2) as the primary authentication mechanism. Support
platform authenticators (Touch ID, Windows Hello, Android biometrics) and
roaming authenticators (YubiKeys, Nitrokeys) via the WebAuthn API. The server
validates assertions using a WebAuthn-compatible Rust library.

## Consequences

- Positive: phishing-resistant, passwordless authentication by default.
- Positive: WebAuthn is a W3C standard with broad platform support.
- Positive: eliminates password storage and hash verification on the server.
- Negative: requires a WebAuthn-compatible browser or client runtime.
- Negative: account recovery without a hardware authenticator needs a fallback
  (see ADR-007).

## Alternatives Considered

- **Password + TOTP**: usable but phishable.
- **Magic-link email**: not suitable for high-security environments.
