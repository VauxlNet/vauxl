# ADR-002: Primary Language — Rust

**Status:** Accepted
**Date:** 2026-01-01

## Context

The implementation language determines memory safety guarantees, ecosystem
reach, team productivity, and audit outcomes. Vauxl's requirements include
cryptographic safety, concurrent event processing, and cross-platform client
delivery.

## Decision

Use Rust as the primary implementation language for the server and the client
core. Rust provides memory safety without a garbage collector, a strong type
system, a mature async ecosystem (Tokio), and a unified toolchain (Cargo)
across all components.

## Consequences

- Positive: memory safety guarantees eliminate an entire class of security
  vulnerabilities (buffer overflows, use-after-free).
- Positive: unified toolchain across server, client core, and crypto.
- Positive: strong ecosystem support for Matrix (ruma), cryptography
  (vodozemac, dalek), and async HTTP (axum).
- Negative: steeper learning curve for new contributors.
- Negative: compile times are longer than Go or Python.

## Alternatives Considered

- **Go**: simpler concurrency model but weaker cryptographic ecosystem.
- **Python**: faster iteration but no compile-time safety guarantees for
  security-critical paths.
