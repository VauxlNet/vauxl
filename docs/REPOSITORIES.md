# Repository Map

## Active
- `VauxlNet/vauxl` (this meta repo)
- `VauxlNet/folio` (docs renderer for `docs.vauxl.net`, also shipped as a standalone project)
- `VauxlNet/website`
- `VauxlNet/client`
- `VauxlNet/server`

## Planned
- `VauxlNet/matrix-spec` (versioned Vauxl Matrix extension contracts, repo not yet created)

Each component repo owns its own `docs/` directory. Folio aggregates them into `docs.vauxl.net`. There is no central docs repository.

## Archived
Previous generation repositories are archived and renamed with the suffix `-legacy-v1`.

Examples:
- `VauxlNet/app-legacy-v1`
- `VauxlNet/core-legacy-v1`
- `VauxlNet/platform-legacy-v1`
- `VauxlNet/platform-api-legacy-v1`
- `VauxlNet/server-legacy-v1`
- `VauxlNet/turn-legacy-v1`
- `VauxlNet/auth-legacy-v1`
- `VauxlNet/vauxl-legacy-v1`
